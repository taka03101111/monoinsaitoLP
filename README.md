# monoインサイト LP リニューアル

添付ワイヤーフレーム修正案、紹介資料、10/9議事録、既存LPをもとに作成した静的Webサイトです。

## ファイル

- `dist/index.html`：LP本体
- `dist/style.css`：レスポンシブデザインとアニメーション
- `dist/app.js`：4ステップの操作デモ、字幕編集体験、注意マーク、モバイルメニュー
- `dist/download.html`：紹介資料のダウンロード
- `dist/contact.html` / `support.js`：メール作成型の相談フォーム
- `dist/assets/`：製品画面、公式工場写真、提供された紹介資料PDF

## 表示・公開方法

`dist/index.html`をブラウザーで開くか、`dist`をWebサーバーのドキュメントルートとして配信します。ビルド・npmインストールは不要です。相対パスで構成しているため、GitHub Pagesのサブディレクトリにも配置できます。

既存 `monoinsaitoLP` リポジトリへ反映する場合は、現在のソースをバックアップし、公開元のフォルダへ `dist` **内のファイル**を配置してください。本作業では元のGitHubリポジトリや既存ドメインは更新していません。

## 反映内容

- 「製造業の自社現場から生まれたAI」を冒頭と開発背景で訴求
- オレンジと濃紺の配色、強弱のある見出し、実画面・公式工場写真
- 課題→機能の対応、4ステップの操作デモ、簡単な編集体験
- 標準書に沿った出力、急所付き作業標準書のイメージ
- 一般動画編集・改善支援ツールとの用途・設計比較
- 月額45,000円〜（税抜）、初期費用別途、詳細資料への誘導
- カイゼン機能は開発中、詳細ボタン無効化
- PC・スマートフォン対応、キーボード操作、動きを減らすOS設定に対応

## 現在の実装境界

LP内のアニメーションと操作デモは、事前に用意したサンプルです。実際の動画アップロード・AI解析・マスキング・作業標準書生成をこのLPでは実行しません。作業者名や字幕はデモ用で、保存しません。

提供されたファイルと既存LPには完成した操作動画がなかったため、製品スクリーンショットとHTML/CSS/JSによる操作デモを使用しています。実録動画が完成したら、操作デモ部分に`video`要素を追加して差し替え可能です。

問い合わせは入力内容からメールアプリを開く方式です。実際の送信は利用者がメールアプリで行います。送信API、自動返信、即時アカウント発行は未接続です。無料トライアルの期間・範囲・開始条件が未確定のため、相談導線として実装しています。

紹介資料PDFは添付の紹介資料をそのまま収録しています。開発中機能や将来計画も含む旨をダウンロードページで案内しています。

## AIの実接続を行う場合

議事録のサーバー・認証・モデル仕様が確定した後、PHP等のバックエンドAPIを別途実装してください。Claude APIキーはサーバーの環境変数またはシークレット管理に保存し、HTML・JavaScript・Gitリポジトリへ含めない構成にします。

実接続時には認証・同意・アップロード上限・動画形式の検証・利用回数制限・バックグラウンド解析・保管期限・アクセス制御・ログからの秘匿情報除外・CORSの許可元を決定します。本成果物にAPIキーは含まれていません。
