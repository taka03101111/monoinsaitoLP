旧画像にはお客様名の写り込みがあるため、アップロード前にリポジトリ内の `assets/images/manual-tablet.webp` と `assets/images/manual-library.webp` を削除してください。過去に `public_html/` などをアップロードしている場合は、その中の同名ファイルも削除してください。新しいファイルのアップロードだけでは、既存の旧画像は削除されません。

このZIPには旧画像を含めていません。過去のGitコミットには残るため、履歴からも完全に削除する必要がある場合は、別途履歴の整理が必要です。

## アップロード方法

1. ZIPを解凍し、このREADMEと `index.html` があるフォルダを開きます。
2. GitHubのリポジトリで **Add file → Upload files** を選びます。
3. このフォルダの**中身全部**をアップロードしてコミットします。外側の `mono-insight-github-pages-20261117` フォルダごと入れないでください。
4. リポジトリの **Settings → Pages** で **Deploy from a branch**、ブランチ **main**、フォルダ **/(root)** を選んで保存します。
5. 公開処理が終わったら、Pages画面に表示されるURLを開きます。

リポジトリ名は自由です。ユーザー用サイトのルートでも、`https://ユーザー名.github.io/リポジトリ名/` でも使える相対パスに調整しています。

## 入れるもの

- index.html
- assets/（CSS・JavaScript・公式ロゴ・画像・最新版紹介動画）
- demo/（サンプルの字幕・表示時間・手順編集画面）
- contact/、download/（フォームの画面確認）
- .nojekyll、README.md

`.nojekyll` は隠しファイルです。見えない場合はGitHubの「Create new file」から `.nojekyll` という空ファイルを作成しても構いません。

## 本番との違い

GitHub Pagesは画面確認用です。AI解析、動画アップロード、問い合わせ送信、受付記録、メール自動返信、資料PDFの配布は実行しません。フォームにはその旨を表示し、送信したように見せる処理も入れていません。APIキー、PHP、非公開設定、受付データ、配布用PDFは含めていません。

LP・フォームをXserverで公開する際は、別途用意した `mono-insight-xserver-20261117.zip` を使ってください。本番の解析APIは先方との接続作業が必要です。このGitHub用フォルダだけでローカル解析アプリを起動することはできません。

フォルダをダブルクリックして開くと一部のブラウザー機能が使えません。動作確認はGitHub Pagesで公開したURLで行ってください。
