# monoインサイト LP / 実AIデモ統合版

このLPは同梱のローカルサーバーと組み合わせて使用します。配布フォルダーの「はじめに.html」を読み、「3-起動.cmd」から開いてください。HTMLを直接開いた場合、AIデモは起動しません。

「撮った動画が、そのまま現場の標準に。」から `/demo/?embed=1` の実アプリを同一オリジンのiframeに表示します。入力・解析・編集・保存はデモアプリ側で行います。APIキーは同梱せず、サーバー側の設定を使用します。

LPの問い合わせ・資料フォームは元の確認用仕様を維持しています。メール送信は行いません。
