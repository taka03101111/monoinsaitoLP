# monoインサイト LP — フィードバック反映版

20261014_monoインサイト_LP_フィードバック.pptx と「白ベースへ戻す」というご指示を反映した静的Webサイトです。

## 表示方法

配布ZIPは解凍して `index.html` をブラウザーで開いてください。開発用リポジトリでは `dist/index.html` です。ビルドや依存パッケージのインストールは不要です。

## 今回の変更

- 白を基調に、濃い文字とオレンジのアクセントへ変更。
- 見出し上の英語ラベル、細かな装飾文、課題セクションの重複した補足を削除。
- 本文16px、補助文14px以上。画像内の製品UI文字は原本を保持。
- 「言葉やアカウントが教育の壁になる」の課題行と「精度へのこだわり」を削除。
- 仮の図形アニメーションを製品画面へ変更。提供資料の編集画面・マニュアル詳細画面を追加。
- ご指定により、LP内の「作業の概要」入力欄を削除。
- 作業標準書を製品UIの配色と書式に合わせた表示例へ変更。「品質・安全・作業のポイント」を強調。
- 比較対象を「動画マニュアル作成ツール」へ変更し、比較内容も更新。
- 削除保留の使用場面セクションは維持。
- 資料ダウンロード・お問い合わせも白ベースへ統一。

## ファイル

- `index.html` / `style.css` / `editorial.css`：LP本体と白ベースのデザイン
- `app.js`：4ステップのサンプル、字幕入力
- `download.html` / `contact.html`：資料請求・お問い合わせ
- `forms.css` / `forms-white.css` / `support.js`：フォームのデザインと画面遷移
- `assets/`：製品画面、工場写真、紹介資料PDF

## 実装範囲

操作デモは製品スクリーンショットを使ったサンプルです。AIによる内容生成や動画アップロードは実装していません。デモの字幕入力はブラウザー内のメモリにのみ保持し、送信・保存しません。

お問い合わせと資料請求はデザイン確認用です。実送信先は未定のため、送信・保存・メール送付は行いません。お問い合わせの受付番号は表示サンプルです。資料請求では入力と同意後に提供資料PDFへのリンクを表示します。

作業標準書は実画面の画像が未提供のため、資料内の製品UIを参考にした出力イメージです。実際の標準書画面と同一であるとは表示していません。

カイゼンは開発中と表示し、詳細ボタンを無効化しています。月額45,000円〜（税抜）、別途初期費用、年間契約・月次請求の表示を維持しています。

## 素材

- 追加した編集・マニュアル詳細画面：提供紹介資料PPTX内の原画像
- 既存の製品画面：元LPから取得済みの画像
- 工場写真：株式会社オーテック公式採用ページ
- PDF：ユーザー提供の紹介資料（11ページ）
- フォント：Zen Kaku Gothic New。Google Fontsへ接続できない場合は端末の日本語フォントを使用

元のGitHubリポジトリと既存ドメインはこの成果物の配布によって変更されません。公開する場合は配布ZIP内のWebファイルを公開元へ配置してください。

## 追加修正

画面の拡大ボタン・ダイアログ・クリック操作をすべて削除。作業標準書は、概要説明、資料内の動画マニュアル画面、読みやすい標準書の表示例、品質・安全・作業のポイントの説明、確認とPDF出力の順に再構成しています。`standard.css` がこのセクションのレイアウトを管理します。
